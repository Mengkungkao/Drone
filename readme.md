# DroneLab

DroneLab is a modular desktop engineering application for Betaflight, PX4, and drone simulation. The React/TypeScript, Tauri/Rust, SQLite and safety foundation is built and its launch gate is verified: the shipped binary runs, persists a project and a configuration snapshot, and reloads them along with a latched emergency stop after a restart. Hardware integration and measured flight milestones remain gated.

The project is in [drone-platform](drone-platform/README.md). Start with the [architecture](drone-platform/docs/architecture.md), [development workflow](drone-platform/docs/development.md), and [current phase gates](drone-platform/docs/roadmap.md).
