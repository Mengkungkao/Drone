# DroneLab

DroneLab is a modular desktop engineering application for Betaflight, PX4, and drone simulation. Development begins with the React/TypeScript, Tauri/Rust, SQLite, and safety foundation. Hardware integration and measured flight milestones remain gated.

The project is in [drone-platform](drone-platform/README.md). Start with the [architecture](drone-platform/docs/architecture.md), [development workflow](drone-platform/docs/development.md), and [current phase gates](drone-platform/docs/roadmap.md).
